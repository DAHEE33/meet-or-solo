# 검색엔진 크롤러 규칙.
#
# 공개 전까지는 운영 nginx가 X-Robots-Tag: noindex, nofollow 헤더를 보내고 있어서
# 이 파일이 허용하더라도 검색 결과에 오르지 않는다. 그 헤더가 우선한다.
# 공개 시 nginx에서 헤더를 지우면 이 규칙이 실제로 동작한다.
#
# 개인 화면은 로그인이 필요해 크롤러가 내용을 볼 수 없지만, 주소가 검색 결과에
# 노출될 이유도 없어 막아 둔다.

User-agent: *
Allow: /
Disallow: /admin/
Disallow: /mypage/
Disallow: /match-room
Disallow: /check-in
Disallow: /profile/edit
